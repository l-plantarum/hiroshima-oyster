# 中下2023完全照合・DO原表抽出・2023反証ケース解析

## R²差の特定

図11・図12を300 dpiでデジタイズし、図12の2000～2020年21点から再計算したR²は **0.5117** で、論文記載0.5122を再現した。したがって図デジタイズの軸較正は妥当である。

- 論文点の2001～2019年だけにするとR²=0.4533。2000年・2020年を落とす標本期間差だけで約0.058低下する。
- 同じ論文積算水温に今回の公式年報由来へい死率を入れてもR²=0.4536でほぼ不変。へい死率復元は主因ではない。
- 今回の積算水温へ置換するとR²=0.3527。差の主因は積算水温系列である。
- 2002年公式HTMLは表本文が2001年値の複製で、今回も2001年と同じ積算値になった。2014年は観測13件、2015年は1件しか解析表に入り、不完全な年を年間積算値として扱っていた。2020年は表層水温自体が欠測、2000年は対象外だった。
- それ以外の年も論文図12より概ね30～80℃・日低い。論文は図12を水深0.5 mと表記し、今回のマスターは公開表0 mを使用する。論文の年度別数値表は公開されていないため、残差は0/0.5 m表記、取得時点の原表版、地点平均・丸めの差を著者データなしに完全分離できない。

## DO抽出

2013～2023年の年報から、2015年を除く10年、計149調査日のDO行を抽出した。各行は津久根・似島学園・江波の同日3地点平均であり、地点別生値ではない。個別地点値へ分解していない。2015年は機器故障による公式欠測である。

Jul–Sepと10月1日前14/30/60日について、深度別最低値・平均値、DO<4/3/2 mg/Lの観測回数・観測割合、閾値不足量（mg/L・観測）を作成した。調査日間の補間や日数換算は行っていない。

## モデル判定と2023年

事前指定モデルを同一標本で比較できる完全ケース数は8年で、最小基準n=20を満たさない。したがってHeat単独、Heat+Salinity、Heat+DO、Heat+Salinity+DO、Heat×DOのLOOCV比較は実施していない。回帰係数や有意性も主張しない。

2023年は積算水温が高い一方、へい死率は33.3%で、Heatモデル予測より約4.1ポイント低かった。年報DOではJul–Sepの10 m・B-1 m指標を2016・2022年および低へい死対照年と並べた。ただし空間平均DOの疎な調査日系列であり、筏地点の連続的低酸素曝露を表すものではない。このため2023年はHeat単独仮説への反証ケースとして保持し、DOが説明したと断定しない。
