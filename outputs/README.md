# 広島湾養殖マガキ大量へい死研究 解析用マスターデータセット

作成日: 2026-10-16（日本時間）

## 収録済み

- 2001-01-01～2026-10-16の日次カレンダー（9,420日）
- 広島市水産振興センター「広島湾内平均」の水温・塩分（0/2/5/10 m、観測日ベース）
- 気象庁・広島地方気象台の日降水量
- 国土交通省水文水質データベース・太田川「矢口第一」の時刻流量から計算した日平均流量
- 広島市水産振興センター年次業務報告書の月別カキへい死率（2001～2023年度、10月～翌5月、184件）
- 上記へい死率から算出した年度別10～12月平均（23年度）
- 取得元URL、取得時刻、観測地点、深度、集計方法、品質フラグ

## 未取得または未統合

- DO: 環境省公共用水域データは年別・地点別・深度別の調和処理が必要で、本実行では検証済み一括取得まで完了していない。
- 衛星SST/Chl-a: MODIS/Sentinel-3/GCOM-Cについて、認証済み・雲品質マスク済み・広島湾画素抽出を実行していない。
- へい死率: 2024年度は同一定義の広島市年報を未確認。2025年は水産庁の地域別聞き取りレンジを別表に保存したが、長期の市内業者月別系列とは定義が異なるため日次マスターには結合していない。

未取得項目はmaster上で空欄とし、`*_quality_flag` に未取得理由を明記している。ゼロとは解釈しないこと。

- `hiroshima_bay_oyster_master_daily_v2.csv`: へい死率統合済み日次ワイド形式マスター

## 結合方針

マスターは日付のみを共通軸にした左結合である。観測地点、深度、集計方法が異なる値を同一観測とは扱わない。水温・塩分は広島湾内平均の離散観測、降水は広島地方気象台の日合計、流量は矢口第一の利用可能な時刻流量の日平均である。へい死率は月次値を各月1日の観測キーにだけ結合し、日次補間・月内複製はしていない。RainとRiverは独立列・独立メタデータとして保持する。

## 利用上の注意

2026年は10月16日までの部分年。水温・塩分は毎日観測ではなく、観測日のみ値がある。河川流量は時刻値が24件未満の日に `incomplete_day` を付与する。欠測補間は行っていない。
