# マガキへい死データ取得計画

## 優先順位1: 2025年広島県生産者72名ヒアリングの集計原表

広島県の有識者会議概要は、2026年2～3月に県内全域の生産者72名を調査し、発生時期、沖合・沿岸、垂下深度、養殖期間とへい死率の違いを分析したことを明記している。公開されている概要では個票・分母が省略されているため、広島県農林水産局水産課へ次の匿名化集計表を依頼する。

必要列:

- survey_date / mortality_start_date / peak_date
- municipality / sea_area / offshore_or_coastal / farm_or_raft_id（匿名ID可）
- oyster_age_or_culture_duration / seed_origin / hanging_depth_m
- examined_n / dead_n / alive_n / mortality_rate_pct
- denominator_definition / observation_method / respondent_or_direct_count
- gear / density / management actions
- source_document / quality_flag

個人・事業者識別情報は不要。少なくとも海域×沖合沿岸×養殖期間×深度別の `dead_n` と `examined_n` を依頼する。

## 優先順位2: 広島県議会資料と水産庁聞取り資料

- 県議会の2025年11月・12月資料にある地域別へい死割合の表・図を原表優先で回収する。
- 水産庁資料は広島県西部3～9割、中部・東部7～9割など範囲値であり、モデルの目的変数ではなく、地域・時点付きの検証用レンジとして保存する。
- 範囲値は中央値へ変換せず、`mortality_rate_lower_pct` と `mortality_rate_upper_pct` に分ける。

## 優先順位3: 中下ら（2023）の著者データ

論文は5年間、深度別にへい死率を実測し、1988～2020年の水温・塩分・へい死率も扱っている。本文図のデジタイズ前に、責任著者へ解析表または補足データの提供を依頼する。

依頼対象:

- 5年間の調査日×地点×深度別の死亡数・生存数
- 1988～2020年へい死率系列の原典、分母、集計期間
- 水温・塩分との対応地点および時間集計定義

図しか得られない場合に限りデジタイズし、`quality_flag=digitized_from_figure`、図番号、軸範囲、読取り誤差を保持する。

## 優先順位4: 行政文書開示・研究データ提供依頼

通常照会で個票または匿名集計が得られない場合、広島県の行政文書開示制度を検討する。対象文書名は「令和8年2～3月実施、県内かき生産者72名ヒアリングの調査票、匿名化回答データ、集計表、会議配布資料」。個人・法人名、位置の精密座標は不開示可と明記し、研究に必要な分母・分子・海域区分の提供を優先する。

## 採用基準

- A: 直接計数による dead_n / examined_n
- B: 生産者回答だが分母・期間・海域が明確
- C: 行政集計の範囲値または定性的区分
- D: 論文図からのデジタイズ

A/Bを推定モデルに使用し、Cは検証・感度分析、Dは最後の手段とする。年次生産量減少や出荷量減少をへい死率の代替値として無断使用しない。
