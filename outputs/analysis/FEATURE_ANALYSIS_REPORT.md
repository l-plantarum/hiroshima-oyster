# 特徴量解析 v1

作成日: 2026-10-16

## 設計

- 年別fingerprintはカキの高温・産卵・へい死が問題になりやすい6～10月で固定集計した。
- 降水と流量は日次値から集計した。
- 水温・塩分は実観測日のみ使用し、日次補間していない。このため、閾値超過日数と積算値は「観測回数」「観測日積算」であり、連続的な曝露日数ではない。
- ラグの正値は、説明変数が応答変数より先行することを表す。
- 2002・2016・2022年は、へい死原表で未確認の候補年。2025年のみ公式資料で大量へい死年と確認できる。

## 暫定結果

1. `Rain → River` は1日ラグが最大で、Pearson r=0.611、Spearman r=0.367（n=8,760）。降雨後に矢口第一流量が増える時間構造と整合する。
2. `River → surface salinity` は1日ラグで最も強く、Pearson r=-0.669、Spearman r=-0.626（n=1,133）。流量増加後に表層塩分が低下する関係が明瞭だった。
3. 深くなるほど流量との同時～短期関係は弱くなった。2 mは最大Spearman r=-0.433（2日）、5 mは-0.227（14日）、10 mは-0.102（28日）。深層の弱い最大相関や長いラグは、独立した因果遅延と断定できない。
4. 2025年6～10月の表層水温は平均26.16℃、最高30.1℃、28℃以上の観測が8回で、候補年4年の中で最も高温だった。最大無降雨連続日数も19日で最長だった。
5. 2025年の矢口第一流量は公式DBの時刻値が未収録のため季節指標を計算できない。2025年を含む完全な `Rain → River → Salinity` 比較には流量確定値の公開または別の公式流量資料が必要。

これらは自己相関、季節性、観測間隔の不均一性を調整していない探索的結果であり、p値や因果効果として解釈しない。
