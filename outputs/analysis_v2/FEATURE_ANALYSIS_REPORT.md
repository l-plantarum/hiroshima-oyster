# へい死率統合後の特徴量分析

作成日: 2026-10-16

## 対象と時間設計

- 目的変数: 広島市水産振興センター年報から復元した各シーズンの10～12月平均へい死率。
- 説明変数: 同じ年の6～10月の水温、塩分、降雨、矢口第一流量。
- 対象: 2001～2023年度の23シーズン。水温・塩分を含む完全ケースは21シーズン。
- 月別へい死率を日次に複製せず、年度表から直接目的変数を作成した。
- DOは未取得のため除外した。欠測値の代入は行っていない。

## 主な結果

単変量では、平均へい死率との絶対相関が大きかった特徴は `Heat×Salinity`（Pearson r=0.514）、最長無降雨期間（r=-0.441）、表層平均塩分（r=0.407）、観測日ベース25℃超過量（r=0.374）だった。置換検定の未調整p値はそれぞれ0.0155、0.0338、0.0683、0.0911である。多数の特徴を探索しているため、最初の2項目も確証的有意差とは扱わない。

LOOCVで最も誤差が小さかったモデルは `Heat + Salinity` だった。21シーズンで R²=0.313、調整済みR²=0.237、LOOCV RMSE=7.92ポイント、MAE=6.63ポイントである。同じ21シーズンの除外平均ベンチマークに対するRMSE改善は5.3%に留まった。

`Heat + Rain + River + Salinity` は R²=0.318だが、調整済みR²=0.148、LOOCV RMSE=8.82ポイントで、2変数モデルより汎化性能が悪かった。さらに `Heat×Salinity` を加えた5変数モデルはLOOCV RMSE=13.12ポイントまで悪化した。現標本では、交互作用を含む高次モデルは過学習している。

## Rain → River → Salinity

日次ラグ解析では、降雨から矢口第一流量への最大関連は1日後（Pearson r=0.611）、流量から表層塩分への最大関連も1日後（r=-0.669）、降雨から表層塩分は3日後（r=-0.351）だった。方向は想定どおりだが、季節性・自己相関を除去していない記述相関である。

## へい死年

- 最大: 2007年度 54.0%
- 2022年度: 48.0%（上位四分位）
- 2002年度: 43.0%（上位四分位）
- 2016年度: 39.7%（中位群）
- 最小: 2015年度 17.7%

2023年度は観測日ベースの高温指標が大きい一方、へい死率は33.3%だった。高温単独では年度差を十分説明できず、塩分、曝露時期、養殖条件、DO等を含める必要があることを示す。ただしこれは因果推定ではない。

## 解釈上の制約

- n=21～23であり、説明変数を増やしたモデルは不安定。
- 水温・塩分は離散観測。`obs_degree_days_above_25c` は観測日における超過量合計で、連続日積算ではない。
- 調査業者数・分母・地点・深度が年度別累積表では不明。
- 自己相関、非線形性、媒介効果、年度別養殖条件は未調整。
- p値は探索用の置換検定で、多重比較補正を行っていない。

## 次の分析優先順位

1. 水温観測間を上限付きで補間した連続的な高温曝露指標を感度分析として作る。
2. Rain→River→Salinityを季節性除去後の分布ラグモデルで検証する。
3. DOを取得し、Heat×DOを追加する。
4. 年度別の調査業者数・養殖深度・養殖開始時期を回収し、へい死率の測定構造を調整する。
5. 2024・2025年度を同一定義で追加できるまで、長期系列と2025年イベントレンジを分離する。
