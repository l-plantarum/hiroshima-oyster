# 中下ら2023再現・因果経路分析

## 原論文から固定した定義

中下ら（2023）の積算水温は、各年で最も水温が低い日を開始日、9月30日を終了日とし、広島湾5地点の平均表層水温から10℃を差し引いた値を積算する。10℃以下はゼロとし、週次観測間は線形内挿する。目的変数は10～12月の平均へい死率である。論文の2000年以降の回帰は R²=0.5122。

## 再現結果

現在のマスターで利用できる2001～2020年について同じ計算を実施した。2020年は表層水温系列が欠測のため、回帰は19年となった。

- R²: 0.353
- Pearson r: 0.594
- LOOCV RMSE: 7.55ポイント
- 論文との差: R²で -0.160

正の関連自体は再現したが、説明力は完全再現できなかった。考えられる差は、2000年の欠測、2020年の水温欠測、0mと論文記載の表層・0.5mの差、5地点平均の構成、原観測値・丸め・補間端点の差である。したがって、現時点では論文結果を否定せず、入力系列の同一性が未確定と判断する。

## 時間窓

絶対相関が比較的大きかった組み合わせは以下だった。

- 7～8月の観測日ベース25℃超過量: r=0.491
- 8～9月の観測日ベース25℃超過量: r=0.457
- 7～10月の最長無降雨期間: r=-0.447
- 8～9月の平均表層水温: r=0.432
- 6～10月の平均表層塩分: r=0.407
- 8～9月降水量: r=-0.377

高温については6～10月全体より7～9月の方が強い。一方、無降雨期間とへい死率の符号は仮説と逆であり、少雨を単純な直接効果として解釈できない。

## Heat + Salinity + interaction

- 主効果2項: R²=0.313、調整済みR²=0.237、LOOCV RMSE=7.92
- 主効果＋交互作用: R²=0.321、調整済みR²=0.201、LOOCV RMSE=11.34
- 標準化交互作用係数: -0.727ポイント

3項に限定しても交互作用による当てはまりの増加は小さく、外部予測誤差は悪化した。ただしn=21なので「交互作用なし」の確証ではない。少なくとも現在の線形積モデルは予測に使うべきではない。

## 季節性を除いた Rain → River → Salinity

各系列から暦月別平均を引いた偏差系列で再検証した。

- Rain → River: 1日後、r=0.602
- River → 表層Salinity: 1日後、r=-0.660
- Rain → 表層Salinity: 2日後、r=-0.401

AR(1)による有効標本数近似を適用しても関連は残った。媒介経路の方向性は頑健だが、正式な因果媒介効果ではなく、共通季節性以外の交絡や非線形応答は残る。

## 残差年

2001～2023年の利用可能年で積算水温モデルを再推定すると、2023年度の実測へい死率は33.3%、予測37.4%、残差-4.1ポイントだった。大きな極端外れではないが、「積算水温から期待されるより低い」negative residual yearである。2011年度も残差-3.9ポイントで近い対照年となる。

最大の正残差は2007年度（2001～2020年モデルで+17.6ポイント）であり、高温以外の増悪要因を探す上では2023年と対になる重点年である。

## DO取得経路

広島市水産振興センター年次業務報告書には、広島湾内の0、2、5、10、B-1mのDOが表形式で掲載されている。DOは広島湾内5地点すべてではなく、津久根・似島学園・江波の平均である。少なくとも平成28年度、令和2年度、令和3年度、令和5年度について表の存在を確認した。

水温・塩分の5地点平均とは地点構成が異なるため、DOを同一観測とみなさず、`station_set`, `depth`, `aggregation`, `method` を保持して別系列として取り込む必要がある。

## 次の作業

1. 年次業務報告書からDO表を年別に機械抽出し、原表画像と照合する。
2. 2020年の水温欠測と2000年データを補い、論文R²の再現を再試行する。
3. 2023・2011・2007年について、底層DO最低値、DO<3mg/L継続期間、深度別DOを残差と照合する。
4. DO取得後は `Heat + Salinity + DO` と、事前に限定した `Heat×DO` をLOOCVで比較する。
